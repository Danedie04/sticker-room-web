Sticker assets can be placed here in subdirectories:
- /public/stickers/plants/
- /public/stickers/decor/
- /public/stickers/pets/
- /public/stickers/furniture/
- /public/stickers/food/
- /public/stickers/misc/

The app uses emoji-based stickers by default, so no image files are required
for the base functionality. Custom PNG sticker packs can be added here and
referenced in /lib/stickers.ts
